# Cosmic English Learning

A responsive, space-inspired English learning website with small activities for six core skills.

## What's included

- Listening lab with browser text-to-speech
- Reading passage and comprehension check
- Vocabulary flashcards
- Present simple grammar guide and quiz
- Speaking prompt generator
- Writing area with a local word counter
- Search, mobile navigation, and light/dark theme
- Curated external learning resources

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Deploy with GitHub Pages

The workflow in `.github/workflows/pages.yml` publishes the static site from the `main` branch. In the repository, set **Settings → Pages → Build and deployment → Source** to **GitHub Actions** if it is not already selected.

## Content note

This repository contains a refreshed starter experience and newly written practice activities. The original Google Sites page remains linked in the About section; its existing lesson content should be reviewed and migrated into this site before treating this as a full content replacement.
